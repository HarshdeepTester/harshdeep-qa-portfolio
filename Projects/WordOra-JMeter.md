# WordOra Performance Testing

## Project Overview

Performed performance testing on the WordOra web application using Apache JMeter to evaluate application stability and response time under load.

## Testing Scope

- Load Testing
- Performance Testing
- Response Time Analysis
- Stress Testing

## Activities Performed

- Created a JMeter test plan.
- Simulated approximately 130 concurrent users.
- Measured response time and throughput.
- Identified potential performance bottlenecks.
- Documented test results and observations.

## Tools Used

- Apache JMeter

## Skills Used

- Performance Testing
- Load Testing
- Test Planning
- Result Analysis
- Reporting

## Outcome

Successfully executed performance tests and analyzed the application's behavior under concurrent user load.
