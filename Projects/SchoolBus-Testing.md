# SchoolBus 2.0 Login Testing

## Project Overview

Conducted manual testing of the SchoolBus 2.0 login module as part of a QA assessment. The objective was to identify functional, UI/UX, input validation, and error handling issues.

## Testing Scope

- Functional Testing
- UI Testing
- Input Validation Testing
- Error Handling Testing
- Cross-Browser Testing

## Activities Performed

- Created and executed test scenarios.
- Tested login functionality with valid and invalid inputs.
- Verified email and password validation.
- Checked error messages and field behavior.
- Performed testing on different browsers.
- Documented defects with severity and reproduction steps.

## Key Defects Identified

- Incorrect validation for empty fields.
- Login type resets after failed login attempt.
- Error messages do not disappear after correction.
- Password field accepts only spaces.
- Invalid email format validation issues.
- Duplicate password visibility icon in Microsoft Edge.
- Inconsistent email field labeling.

## Skills Used

- Manual Testing
- Functional Testing
- UI Testing
- Input Validation
- Bug Reporting
- Test Case Design
- Cross-Browser Testing

## Outcome

Successfully identified multiple functional and UI issues and prepared a structured bug report with screenshots and severity classification.
